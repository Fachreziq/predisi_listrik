# Prediksi Konsumsi Listrik Rumah Tangga

## Deskripsi
Project Machine Learning berbasis Flask untuk memprediksi konsumsi listrik rumah tangga menggunakan algoritma Linear Regression.

## Dataset
Household Power Consumption Dataset

## Algoritma
Linear Regression

## Tools
- Python
- Flask
- Scikit-Learn
- Pandas
- NumPy

## Cara Menjalankan

### Install library
pip install -r requirements.txt

### Training model
python notebooks/train_model.py

### Menjalankan web
python app.py
